# systems/ — game data for the Nuclear Winter game (Nevada Revision 2)

Northern Nevada: Sparks/Reno, the Truckee Meadows and the Lahontan Valley. Player: **Braith Pearce** (25, Air Force crew chief) with **Wraith** (Belgian Malinois).
Pure JSON data plus one validator. Nothing outside `systems/` was edited. Design rationale and the balance tables are in `DESIGN.md`.

```
systems/
  survival.json      stats, rates, thresholds, heat_stress, seasons{}, per-chapter climate (seasonal curve), weather + environment modifiers
  items.json         98 items, legacy aliases, starting loadouts (story copy + systems additions), paper doll
  loot_tables.json   container types, act/season modifiers, per-item seasonal weights, per-chapter areas (v2 locations), act gates
  crafting.json      8 recipes (no story recipes in v2) + 1 story interactive (ch01_water_station)
  weapons.json       14 weapons: melee / ranged / thrown, real-world references, fire modes
  enemies.json       17 enemies, 4 set pieces, encounter groups, chapter curve (story spawns), story encounters
  progression.json   acts/seasons, chapters, gear gates, perks, economy (6 traders, scrip, barter), budget targets
  difficulty.json    4 modes (default = tense_but_fair) + permadeath option
  budget_report*.json   GENERATED by tools/validate.py (do not hand-edit)
  tools/validate.py  validator + resource-budget calculator + story cross-reference
```

## Conventions (all files)
- Ids are stable `snake_case`. Chapter ids `ch01`..`ch10`, location ids `loc_*` (+ `river_ice`), weather ids, trader ids and story item/enemy ids are exactly the ones in `story/gameplay_hooks.json`, `story/items.json` and `story/npcs.json`.
- **Systems acts = seasons** (exact season keys from `gameplay_hooks.seasons`):

| systems act | season key | chapters | story act |
|---|---|---|---|
| `blackout` | `late_summer` | ch01–02 | I |
| `collapse` | `autumn` | ch03–04 | I (ch03) / II (ch04) |
| `civil_war` | `late_fall` | ch05–07 | II |
| `nuclear_winter` | `nuclear_winter` | ch08–10 | III |

  `loot_tables.season_of_act` maps act → season. Trader prices/stock use **story acts** (1/2/3) like `npcs.json`; `progression.economy.story_act_of_chapter` maps chapters.
- Time is **real seconds** unless a field says `per_game_minute` (1 real s = 3.4286 game min, `CFG.dayLenSec` 420). Distances in metres.

## survival.json
- `stats.*`: range, start, `base_drain` (per_real_second + per_game_minute), modifiers, thresholds with effects and HUD cues. `stats.hydration.code_field` = `stats.thirst` (new in code).
- **`seasons{}`**: `late_summer`, `autumn`, `late_fall`, `nuclear_winter` → act, chapters, months, feel.
- **`chapter_climate[chNN]`** (read directly by `Player.tickSurvival`):

| field | meaning |
|---|---|
| `season` | exact season key (equals `gameplay_hooks.chapters[].season`; validator enforces) |
| `ambient_temp_c_day` / `ambient_temp_c_night` | copied from story `temp_c` / `night_temp_c`; HUD TEMP readout |
| `cold_drain_mult` | warmth-drain multiplier by day = max(0, (20 − temp_c) / 25) |
| `night_cold_mult` | **absolute** multiplier at night (same formula on night temp). Do **not** also apply `environment_modifiers.night` |
| `thirst_drain_mult` | hydration multiplier outdoors by day |
| `thirst_drain_mult_night_or_indoors` | hydration multiplier at night or indoors |
| `heat_stress_insulation_threshold` | heat_load above this triggers `heat_stress` (null = off) |
| `radiation_ambient` | `{outdoors_per_real_second, zone}` added outdoors (plus weather/zone rad) |
| `weather` / `weather_weights` | story weather + weights for levels that don't force weather (ids = story `weather_types`) |
| `blizzard_chance`, `fallout_rain`, `outdoor_share` | blizzard window firing share, fallout rain flag, expected outdoor time (budget) |
| `ambient_warmth_regen_per_real_second` | warmth regen when cold mult is 0 (late summer / warm autumn days) |
| `ambient_cold` | legacy alias of `cold_drain_mult` (old code path) |

- **`heat_stress`** (new): `heat_load = Σ heat_penalty` of equipped clothing; daytime only (outdoors ×1, unheated indoors ×0.5, near fire ×1.25); `excess = max(0, heat_load − threshold) × difficulty.heat_stress_mult`; hydration ×(1 + 3·excess, cap 2.5), stamina costs ×(1 + 2·excess, cap 2), stamina regen ×max(0.5, 1 − excess). Status tiers `ok` / `warm` / `overheated` (HUD heat shimmer; death reason "heatstroke" if parched).
- `stats.hydration.free_source.by_season`: `drink_raw` (Truckee / marina / ditch / rain barrel; sick risk) in late_summer–late_fall, `eat_snow` (+5 RAD) in nuclear_winter. `stats.hydration.water_sources` lists every Nevada source (Truckee River, Sparks Marina, irrigation ditches, rain barrels, Steamboat hot springs — boiling doesn't fix minerals, melted snow, cisterns).
- `stats.satiety.companion`: Wraith eats ~2 food items per chapter (counted in the budget).
- `weather_modifiers` covers all 17 weather ids incl. the new `heat_haze`, `dust_wind`, `clear_autumn`, `autumn_wind`, `sleet` (`thirst_mult` on the hot ones).
- `hud_unlocks_from_story` = `gameplay_hooks.hud_unlocks` (hydration from ch01; warmth + TEMP from ch03).

## loot_tables.json
- `container_types` (now incl. `cooler_chest` — picnic coolers / dead vending machines / truck-stop fridges, a late-summer water staple) and `gun_safe` (AR-15 source, needs crowbar/bolt cutters).
- `act_modifiers[act]` (each tagged with its `season`): `empty_chance_add` and `category_weight_mult`.
- `item_act_weight_mult`: **seasonal per-item weights** — winter gear (parkas ×0–0.35 → ×1.6–1.8, snow pants ×0.1 → ×1.6, pac boots ×0.2 → ×1.6, balaclava, insulated gloves…) is rare in late summer and vital in nuclear winter; summer gear (tee, cap) fades to ×0.15; flannel peaks in autumn; ponchos peak in late fall; clean water ×0.6 in late summer.
- `item_act_gate`: earliest act an item can roll (ar15/5.56/arctic parka from `collapse`, military gear from `civil_war`).
- `areas[chNN][]`: one entry per **v2 story location** of that chapter (validator: every story location has an area and vice versa); Ch7 areas carry `level` (`ch07_dead_air` / `ch07b_dixie_valley`). `guaranteed` = hand-placed items (dialogue/effect gives are NOT duplicated here). `flag_gated` on the Ch1 pharmacy uses `kit_dealt`.

## Paper doll (inventory screen)
The inventory screen draws **Braith** as a paper doll; equipped gear appears as stacked sprite layers.
- Asset: `assets/paperdoll/<paperdoll_layer>.png`, base `assets/paperdoll/base_body.png` (Braith Pearce). Every layer **48×96 px**, same canvas, transparent background, pre-positioned, front-facing.
- Draw order: `base_body` → **base, legs, feet, torso, hands, wrap, face, head** → **main_hand** → **off_hand**. One layer per slot.
- Gas mask: if story flag `has_gas_mask` is true, draw `face_gas_mask` (Ch8+).
- Main hand = `player.equipped`; off hand = flashlight (on) or held torch; skip the off hand when the main-hand item is `two_handed`. `tint` = multiply tint. Missing PNG = skip silently.

```js
const ORDER = I.paperdoll.draw_order;
function dollLayers(player, flags) {
  const L = {};
  for (const id of player.equippedClothing) { const it = ITEMS[id]; L[it.slot] = it; }
  for (const f of I.paperdoll.flag_layers) if (flags[f.flag]) L[f.slot] = { paperdoll_layer: f.layer };
  const main = ITEMS[player.equipped]; if (main?.paperdoll_layer) L.main_hand = main;
  if (!main?.two_handed) { if (player.torchHeld) L.off_hand = ITEMS.torch; else if (player.flashlight) L.off_hand = ITEMS.flashlight; }
  return ORDER.filter(s => L[s]).map(s => ({ src: `assets/paperdoll/${L[s].paperdoll_layer}.png`, tint: L[s].tint }));
}
```

## How Prime should load it
Static ES-module site: fetch the 8 files once at boot (unchanged list, so the boot fetch stays stable).
```js
const SYS = "systems/";
const NAMES = ["survival","items","loot_tables","crafting","weapons","enemies","progression","difficulty"];
export async function loadSystems(modeId) {
  const d = Object.fromEntries(await Promise.all(NAMES.map(async n =>
    [n, await (await fetch(SYS + n + ".json", { cache: "no-store" })).json()])));
  d.ITEMS = Object.fromEntries(d.items.items.map(i => [i.id, i]));
  for (const [oldId, newId] of Object.entries(d.items.legacy_aliases)) d.ITEMS[oldId] = d.ITEMS[newId];
  d.WEAPONS = Object.fromEntries([...d.weapons.melee, ...d.weapons.ranged, ...d.weapons.thrown].map(w => [w.id, w]));
  d.ENEMIES = Object.fromEntries([...d.enemies.enemies, ...d.enemies.set_pieces].map(e => [e.id, e]));
  d.TRADERS = Object.fromEntries(d.progression.economy.traders.map(t => [t.id, t]));
  d.MODE = d.difficulty.modes.find(m => m.id === (modeId || d.difficulty.default_mode)).multipliers;
  return d;
}
```
